# RF Post-training 시각화 실험

같은 Rectified Flow 모델에 **RL·직접 역전파·DPO**를 적용해 벡터장, 생성 경로, 도착점 분포와 학습 비용을 비교하는 Google Colab 실험입니다.

[![Colab에서 열기](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/HisameOgasahara/tmp_fm_post/blob/main/rf_post_training_colab.ipynb)

## 실행

1. 위 링크로 노트북을 엽니다.
2. **런타임 → 런타임 유형 변경 → GPU**를 선택합니다. GPU가 없으면 Colab CPU에서 실행합니다.
3. 설정 셀을 확인하고 위에서 아래로 실행합니다.
4. 마지막 셀에서 결과 ZIP을 내려받습니다.

모든 Python 실행과 검증은 Colab에서 수행합니다. 로컬 학습·스모크 테스트를 수행하지 않았으며, 저장소의 노트북에는 실행 결과가 없습니다. 노트북의 `RUN_SIGNAL_CHECKS`는 학습 신호 확인을 실행하고, `RUN_INTEGRATION_CHECK`는 축소된 전체 흐름을 Colab에서 확인합니다. 기본값은 각각 `True`, `False`입니다. 전체 실험은 이 확인용 설정과 별도로 실행됩니다.

## 실험 구성

| 실험 | 피드백 | 비교 |
| --- | --- | --- |
| A | 매끄러운 가우시안 보상 | 세 기법, 기울기 제공·점수만 제공 |
| B | 목표 안 1, 밖 0 | 기본 목표 반경·작은 반경, 성공 샘플·유효 선호 쌍 |
| C | 저장된 고정 선호 기록 | 전체 후보·목표 주변을 제외한 후보, 같은 쌍 수·업데이트 수 |

모델은 반지름 2의 원에 놓인 8개 가우시안 군집을 학습합니다. 군집 표준편차는 0.12, MLP는 128 너비의 은닉층 3개이며 생성은 32단계입니다. 한 번의 수집은 256개, 분포 평가는 고정 잡음 2,048개, 경로 표시는 12개, 벡터장 격자는 25 × 25이며 시드 3개를 사용합니다. 목표 중심은 오른쪽 위 군집입니다.

사전학습 2,500회, 추가 학습 100회를 기본으로 둡니다. 학습률·정규화·PPO·DPO·SDE·그림 설정은 `Config`와 노트북 첫 설정 셀에서 관리하고 실행 결과에 전체 값을 저장합니다. 반복 실행은 새로운 결과 폴더를 만듭니다. 같은 실험 이름을 다시 실행하려면 새 `Experiment`를 만들거나 다른 이름을 사용하세요.

## 학습과 해석

- **RF:** 잡음에서 데이터로 향하는 직선 보간의 속도를 학습합니다. 시간 0은 잡음, 1은 생성 완료입니다.
- **RL:** RF 속도에서 score를 계산해 내부 시간 구간의 SDE 경로를 수집합니다. 최종 보상에서 배치 평균을 빼고 단계별 가우시안 전이 확률비에 PPO clipping을 적용합니다. 수집 당시 모델은 고정합니다. 한 번의 업데이트는 수집 한 번과 `ppo_epochs`회를 포함합니다.
- **직접 역전파:** 최종 보상에서 ODE 생성 단계 전체로 역전파합니다. 점수만 제공하거나 이진 보상을 쓰면 업데이트를 건너뜁니다. 보상 기울기와 업데이트 후 도착점 이동은 다른 패널입니다.
- **DPO:** 고정 후보의 보상으로 선호 쌍을 만들고 동점을 제외합니다. 쌍 안에서 시간·잡음을 공유하며, 현재 모델과 고정 기준 모델의 flow-matching 오차 차이에 로지스틱 선호 손실을 적용합니다. 유효 쌍은 복원 추출하므로 저장된 쌍 수와 서로 다른 가능한 쌍 수를 구분합니다.

RL의 SDE는 양 끝을 피한 구간에서 Euler–Maruyama로 적분하고 양 끝은 짧은 ODE 단계로 연결합니다. PPO는 내부 확률 전이만 사용하며 끝단 ODE 연결은 수집 당시 모델로 고정해 취급합니다. 이 근사 처리의 영향은 `sde_epsilon`과 `sde_noise`를 바꾸어 확인할 수 있습니다. 공통 성능 평가는 같은 Euler ODE로 수행하므로 RL 수집의 SDE 성능과 다를 수 있습니다.

DPO 목적함수는 **RF 예측 오차를 이용한 대리 목적함수**입니다. 정확한 ODE 우도 기반 DPO와 같다고 해석하지 않습니다. 실험 C에서는 저장된 선호 기록만 학습에 사용하고 평가용 보상은 학습에서 분리합니다. 후보가 목표 주변과 모든 군집을 덮는지 Colab에서 확인합니다.

## 비용과 결과 해석

DPO의 평가 수에는 최초 후보 평가를 포함하며 같은 후보를 재사용할 때 추가하지 않습니다. 학습 시간에는 수집·업데이트·DPO 자료 준비를 포함하고 공통 사전학습, 평가, 파일 저장과 그림 생성은 분리합니다. 평가 시간·평가 결과 수는 CSV의 별도 열입니다. 최대 GPU 메모리는 자료 준비와 업데이트 중의 최대 할당량이며 CPU에서는 0으로 기록합니다.

굵은 곡선은 동일 업데이트 횟수에서 시드별 비용과 성능을 각각 평균합니다. DPO의 평가 수는 고정되어 평가 수 축에서 세로 선으로 보일 수 있습니다. 군집 밖 비율은 가장 가까운 군집 중심에서 표준편차의 `outside_sigma`배를 넘는 점의 비율입니다. 높은 보상과 함께 분포 집중·군집 밖 이동도 확인하세요.
